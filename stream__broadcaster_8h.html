Detailed Description

Pushes the latest camera frame to each idle /stream WebSocket viewer (drop-when-busy, low latency).

Sends run inside the HTTP server's own task via httpd_queue_work + httpd_ws_send_frame_async, the thread-safe way to use esp_http_server from another task. Each viewer has one preallocated send job, so the frame path allocates nothing. A viewer still receiving the previous frame is skipped, never queued.
