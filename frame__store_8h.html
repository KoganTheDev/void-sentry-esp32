Detailed Description

Thread-safe home for camera frames: FrameSlots bookkeeping + fixed PSRAM buffers, allocated once.

The mutex guards bookkeeping only - it is never held while copying pixels or sending on the network. Leases release through release_slot(), which takes the mutex, so never destroy a lease while holding it.
