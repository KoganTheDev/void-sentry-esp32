Detailed Description

Motion detector tunables. Defaults are tuned for an indoor scene 1-3 m away.

Member Data Documentation

int tracking::DetectorConfig::fg_age_limit = 34

after this many consecutive foreground frames (~2 s) a cell learns at bg_shift again, so ghosts of a wrong background clear quickly

◆ scene_change_mean_shift

...and only if |frame mean - background mean| also exceeds this (gray levels); a big close object barely moves the mean (auto-exposure)

◆ warmup_frames

int tracking::DetectorConfig::warmup_frames = 17

frames (~1 s) after a (re)seed with no blobs; the background copies the frame each of them, so exposure settling and lamp afterglow are absorbed
