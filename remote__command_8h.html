Detailed Description

Parses the HUD's /commands text messages into typed commands (pure C++20, natively tested).

No Arduino or ESP-IDF headers and no heap use, so the parser runs on the host and in the httpd handler.

Command remote::parse ( std::string_view message)

Parses one message.

Exact, case-sensitive match on the whole view (it need not be NUL-terminated, and the receive buffer is not). Anything unrecognised (empty, unknown text, trailing bytes) yields a Poll command.
