Detailed Description

Versioned, CRC-checked byte layouts for the saved networks and the PIN record (pure C++20, no heap).

Little-endian: magic (u32; "VSWN" nets, "VSWP" pin), version (u8 = 1), count (nets) or set (pin) (u8), fixed-size fields with unused entries zeroed, then CRC-32 of everything before it. Anything that fails a check deserializes to nothing.
