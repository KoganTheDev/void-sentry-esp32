Detailed Description

Runs the control loop: button gestures, the three modes and the published status.

Modes (ControlMode):

  • Ai: the controller leases the latest published frame from the FrameStore (once per new frame sequence), passes it to the BaseDetectionModule, then feeds the track to the aiming::AimPolicy, which yields absolute pan/tilt targets for BaseTurret::set_target_deg (or Home after the target is lost).
  • User: no frames needed; Joystick input is mapped to BaseTurret::jog at most once per kUserModePeriodMs.
  • Calibrate: joystick jogs as in User mode and detection runs so the HUD box shows. A short press records a calibration point (the turret's current angles paired with the visible target's pixel position).

Button gestures: short press toggles Ai/User (or records a point in Calibrate); a long press enters Calibrate, or cancels it and restores the previous mode.

The camera is fixed on the base and the turret aims absolutely, so a calibration is a fixed two-point mapping from image pixels to pan/tilt angles, saved in NVS.
