Detailed Description

How long frame sends block the httpd task (every /stream send runs on it, and so does /commands).

A send returns once the frame is in the socket's TCP send buffer; when the buffer is full it waits for ACKs, up to send_wait_timeout. Counters are since boot, except max_us, which is the longest send since the last take_send_stats() call (the stats line takes it every 5 s).
