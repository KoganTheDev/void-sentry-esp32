Detailed Description

template<typename T>
class vsync::SpinGuarded< T >

A value of type T that owns its own spinlock; every access is one short critical section.

T should be a small trivially copyable struct. load() and store() copy the whole value, update() and inspect() run a callback on the live value under the lock, so a callback must only copy or assign (no blocking calls, no logging, no allocation) to keep the section as short as the hand-written enter/exit pairs it replaces.
