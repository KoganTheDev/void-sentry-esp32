Detailed Description

The /commands WebSocket: parses each HUD message, hands it to the remote sink and replies with JSON metrics.

Request/reply: every received text frame gets exactly one JSON reply (the HUD's poll loop depends on it). Receive and reply buffers live on the httpd task's stack (64 B and 384 B), so there is no heap use per message and nothing to leak when a send fails.
